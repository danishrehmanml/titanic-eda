# Titanic EDA — Exploratory Data Analysis

## Overview
Complete EDA on the Titanic dataset using Python, Pandas, 
Matplotlib and Seaborn.

## Key Findings
- Only 39% of passengers survived
- Females had 74% survival vs males 19%
- 1st class had 64% survival vs 3rd class 24%
- Children had highest survival rate (57%)
- 1st class female → 97% survival (highest survival rate)
- 3rd class male → 13% survival (lowest survial rate)

## Tools Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Dataset
Titanic dataset from Kaggle/datasciencedojo
